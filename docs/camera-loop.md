# Повтор записи вместо камеры

Чтобы скрыть простой или нарушение, вместо живой камеры можно пустить запись по кругу. Система замечает, что кадры повторяются, и сообщает об этом как о нарушении.

## Как отличается запись от живой площадки

Живая площадка кадр в кадр не повторяется. Даже если экскаватор копает циклами, люди, самосвалы, грунт и свет в следующий раз окажутся в другом месте. Запись через период возвращается целиком: отличается только шумом сжатия и часами камеры.

Детектор работает в браузере (`src/sverka/lib/loop.ts`):

1. Каждый кадр камеры уменьшается до 96×54. Кадры хранятся полчаса, около 900 кадров на камеру.
2. Новый кадр сравнивается со всеми кадрами старше 30 с. Ближайший из них — кандидат в повтор, его возраст — период. Общая яркость вычитается, поэтому облако повтором не считается.
3. Близость оценивается относительно движения: разница с ближайшим старым кадром делится на разницу с кадром двухсекундной давности. У записи это несколько процентов: кадры берутся с шагом около 2 с, поэтому совпадают с прошлым проходом с точностью до секунды. У живого рабочего цикла — десятки процентов.
4. Повтор засчитывается, если из последних 12 кадров с движением:
   - 9 повторяют старые с одним периодом ±4 с (или кратным ему: кадр может совпасть с позапрошлым проходом);
   - медианная близость не больше 0,2;
   - не меньше 4 кадров — почти точные копии (не больше 0,08).
5. Кадры без движения пропускаются. Повтор снимается после 12 подряд кадров с движением, которые не повторяются.

Проверка на синтетических потоках: кадры раз в 2 с, сцена 640×360, часы камеры в углу.

| Поток | Результат |
| --- | --- |
| Запись по кругу, 40 с | повтор через 56 с, период 40 с |
| Запись по кругу, 90 с | повтор через 106 с, период 90 с |
| Запись 40 с, шаг кадров 2 ± 0,6 с | повтор через 163 с, период 40 с |
| Живая сцена: экскаватор по сложной траектории | нет |
| Живая сцена: случайное блуждание | нет |
| Рабочий цикл 30 с ± 15 %, прохожий, самосвалы | нет |
| Периодически качается кран, рядом прохожий | нет |
| Неподвижная сцена, медленно меняется свет | нет |
| Цикл 30 с точь-в-точь, больше ничего не движется | повтор — отличить нельзя |

На стенде с тестовой камерой: живая сцена две минуты — повтора нет. После включения записи с периодом 40 с повтор найден меньше чем за две минуты, после возврата живой сцены снят меньше чем за 25 с. Расчёт на кадр — 4–9 мс на камеру.

## Что происходит

- **На кадре** появляется красная плашка «Повтор записи» и строка с периодом. Вердикт: «Камера повторяет запись».
- **Кадры этой камеры** не учитываются в сверке техники.
- **На сервер уходит событие** `STREAM_LOOP` с двумя снимками: «сейчас» и «тот же кадр» период назад. Ответственный получает задачу, событие привязано к камере: две камеры дают два события.
- **Закрывает его только администратор.** Повтор за минуту не исключить, поэтому сервер сам событие не закрывает (`loop_needs_admin`), а по сроку передаёт руководителю. Кнопка «Видео живое — закрыть» есть только у администратора; ответственному сервер отвечает 403.

## Ограничения

- Неподвижную сцену от неподвижной записи не отличить: повторяться нечему.
- Сцену, которая сама повторяется до пикселя и где больше ничего не движется, от записи тоже не отличить.
- Петли короче 30 с и длиннее 30 минут не ищутся.
- Анализ идёт в открытой вкладке. Снимки за полчаса занимают около 10 МБ памяти на камеру.
- Свежая запись, которую не крутят по кругу, повтором не выглядит. От неё защищает канал, а не анализ кадра: поток из ЕЦХД, аутентификация камеры, ГОСТ-VPN.

## Показ

Записи на 30–60 с, пущенной по кругу через VLC как MJPEG, хватит. Повтор появится через два-три прохода. Живую камеру (телефон с IP Webcam) показывайте рядом: на ней повтора не будет.
