# Датасеты Кейса №7: Департамент градостроительной политики города Москвы

Данная папка содержит основные и нормативные материалы для решения кейса по сопоставлению этапов строительства и строительной техники:

1. **[construction_stages_equipment_dataset.csv](file:///d:/LDT_2026/7.ДГП_датасеты/construction_stages_equipment_dataset.csv)** и **[dataset.csv](file:///d:/LDT_2026/7.ДГП_датасеты/dataset.csv)** — нормативный датасет (18 856 записей сопоставления этапов СМР, классов строительной техники, статуса обязательности `mandatory` и ссылок на нормативы `url`). Закодирован в UTF-8 с BOM (`utf-8-sig`) для корректного открытия в Excel на Windows.
   - Также доступны версии в однобайтовой кодировке Windows-1251: **[dataset_cp1251.csv](file:///d:/LDT_2026/7.ДГП_датасеты/dataset_cp1251.csv)** и **[construction_stages_equipment_dataset_cp1251.csv](file:///d:/LDT_2026/7.ДГП_датасеты/construction_stages_equipment_dataset_cp1251.csv)**.
2. **[../README_DATASET.md](file:///d:/LDT_2026/README_DATASET.md)** — полная научно-методологическая и техническая документация: спецификация полей, описание нормативной базы (СП, ТК, 299-ПП, ГЭСН), таблица классов Computer Vision и алгоритмы верификации графика.
3. **[../generate_dataset.py](file:///d:/LDT_2026/generate_dataset.py)** — исходный код генератора онтологии и матрицы сопоставления.
4. **[Сводный перечень строительных работ_ЛТЦ.xlsx](file:///d:/LDT_2026/7.ДГП_датасеты/Сводный%20перечень%20строительных%20работ_ЛТЦ.xlsx)** — исходный сводный перечень работ.
5. **[Ссылки на открыте датасеты.txt](file:///d:/LDT_2026/7.ДГП_датасеты/Ссылки%20на%20открыте%20датасеты.txt)** — перечень внешних датасетов с изображениями спецтехники (Kaggle, Roboflow, GitHub).
6. **Строительная_техника.zip** — архив с тренировочными фотоматериалами.
