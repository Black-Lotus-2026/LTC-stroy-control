# Строй-контроль

Сервис автоматического поиска отклонений на строительных площадках: кадры с
камер видеонаблюдения сопоставляются с календарным планом работ, и система
сама сообщает, что техника, необходимая по плану, отсутствует — или что на
площадке работает техника, не соответствующая текущему этапу.

Команда **Black Lotus**. Хакатон Департамента градостроительной политики
города Москвы.

## Идея в одну схему

```
камера (видеопоток или снимок)
      │
      ▼
   кадр  ──►  детекция (YOLO)  ──►  наблюдения за окно времени
                                              │
календарный план ──► активная работа ──► требования к технике
                                              │
                                              ▼
                                      движок правил
                                              │
                                              ▼
                             инцидент + объяснение + кадр-доказательство
```

Ключевой принцип: **детектор не создаёт инциденты**. Детектор отвечает только
на вопрос «что я вижу на кадре». Решение «это отклонение от плана» принимает
движок правил, сопоставляя наблюдения за интервал времени с требованиями
календарного плана. Поэтому каждое предупреждение объяснимо и проверяемо.

## Запуск

Нужен только Docker.

```bash
make up
```

Поднимутся пять сервисов: API, воркер обработки кадров, планировщик задач,
PostgreSQL и Redis. Миграции применяются автоматически при старте API.

| Адрес | Что там |
|---|---|
| http://localhost:8000/docs | Документация API (Swagger, интерактивная) |
| http://localhost:8000/api/v1/health | Жив ли сервис |
| http://localhost:8000/api/v1/ready | Доступны ли база и брокер |

Загрузить справочник видов работ организаторов (377 наименований):

```bash
make import-catalog
```

Остановить: `make down`. Полный список команд: `make help`.

### Запуск без Docker

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env        # и поправить хосты на localhost
alembic upgrade head
uvicorn app.main:app --reload
```

## Состав API

Полный и всегда актуальный список — в Swagger по адресу
http://localhost:8000/docs. Правила, по которым устроены ответы (конверт
списков, формат ошибок, время, действия над инцидентом), описаны в
[decisions/0006-api-contract.md](docs/decisions/0006-api-contract.md).

| Ручка | Что отдаёт |
|---|---|
| `GET /api/v1/meta/dictionaries` | Подписи значений перечислений: `pending` → «Требует проверки» |
| `GET /api/v1/projects` | Площадки |
| `GET /api/v1/projects/{id}` | Площадка с параметрами наблюдения и составом |
| `GET /api/v1/zones` | Зоны; фильтр по площадке и уровню риска |
| `GET /api/v1/cameras` | Камеры; фильтр по площадке, зоне и состоянию |
| `GET /api/v1/users` | Пользователи — адресаты назначений |
| `GET /api/v1/incidents` | Лента инцидентов: фильтры, поиск, сортировка, страницы |
| `GET /api/v1/incidents/{id}` | Карточка: объяснение вывода, история, кадры-доказательства |
| `POST /api/v1/incidents/{id}/assign` | Назначить ответственного |
| `POST /api/v1/incidents/{id}/status` | Сменить статус или отклонить с причиной |
| `POST /api/v1/incidents/{id}/comment` | Добавить комментарий в историю |

Каждое действие над инцидентом добавляет строку в историю и возвращает
инцидент целиком в новом состоянии — второй запрос за результатом не нужен.

## Структура репозитория

```
data/            исходные материалы организаторов (справочник работ)
backend/
  app/
    api/v1/      HTTP-ручки, по модулю на ресурс
    core/        конфигурация, логирование, формат ошибок
    db/          подключение к базе, базовые классы моделей
    models/      таблицы (SQLAlchemy)
    schemas/     контракты API (Pydantic) — из них генерируется OpenAPI
    services/    бизнес-логика, в том числе движок сопоставления
    cli.py       команды администратора (импорт справочника, сиды)
    storage/     хранилище кадров за интерфейсом (диск сейчас, S3 позже)
    workers/     Celery: задачи и расписание
  alembic/       миграции базы
  tests/
docs/
  decisions/     почему принято то или иное техническое решение
```
